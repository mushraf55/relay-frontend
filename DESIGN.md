# Relay / bright studio

## Direction
A bright, confident workspace with a sunny yellow landing page, vivid blue actions, white work surfaces, and compact navigation. Keep the clean structure of the original reference while giving the product more color and contrast.

## Color
- Ink: #142c43
- Primary action / selected navigation: #1554db with white text
- Landing hero and onboarding canvas: #ffdf70
- Sidebar: #e8f2ff
- Work surfaces: white
- Borders: #d6e2eb
- Supporting colors: coral, teal and golden yellow for identities and overview cards

## Typography
Segoe UI / Arial for the compact application. Strong, tightly spaced landing headlines and readable navy text. Distinct headings, useful secondary text, visible focus rings, and consistent button hierarchy.

## Layout and components
Responsive landing page, Clerk account screens, onboarding and a sidebar dashboard. Mobile navigation collapses. Dense source rows and chatbot cards remain on white surfaces. Colored metric panels help distinguish categories without sacrificing readability. AI messages retain line breaks, show busy/error states, and open cited excerpts in accessible dialogs.

## Functional state
Clerk accounts, Supabase persistence, Stripe billing, private R2 document storage, Upstash limits, background file processing, public shared rooms, and the website widget are connected. Text, FAQ, PDF, DOCX, TXT, Markdown and connector snapshots use real Ollama embeddings and retrieval. Playground, `@relay` group mentions and widget questions call the configured model. General crawling, OCR, recurring connector sync, and notifications remain future work.
